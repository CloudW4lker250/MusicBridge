# Ограничения MusicBridge 1.0.0

- Проверки на основном компьютере и обратная связь пользователя не покрывают все сочетания Windows, оборудования и плееров. Независимая проверка 1.0.0 на чистой Windows 10/11 не проведена. Предыдущий rc44 отдельно проверялся автоматизированно на Windows Server.
- Источник должен предоставлять Windows-медиасессию. Некоторые источники не поддерживают перемотку, громкость или переключение треков; MusicBridge не может добавить эти команды в сам плеер.
- Текст, тайминги и обложки зависят от сторонних каталогов. Возможны отсутствие, задержки и неверное совпадение. Подсветка слов требует временных меток слов; обычный текст не даёт точной синхронизации.
- Визуализатор мини-плеера реагирует на общий звук устройства вывода, включая другие приложения. Это анализатор частот, а не регулировка эквалайзера.
- Автоматический игровой режим использует список процессов и может потребовать ручного добавления игры. Работа поверх эксклюзивного полного экрана не гарантируется.
- Данные музыки и управление на обоях требуют MusicBridge либо доступных метаданных Wallpaper Engine; самостоятельные функции перечислены в руководстве. Установка EXE не заменяет файлы проекта обоев.
- Погода требует интернета. Определение города по IP приблизительное, VPN влияет на результат. Погодные эффекты не применяются к космической сцене.
- Установщик не имеет подписи издателя Windows. Подпись обновлений — отдельный механизм защиты.
- Ранее встречалась нативная авария Wallpaper Engine. В последнее время пользователь её не наблюдает; причина не установлена, окончательное исправление не заявляется.

Удаление приложения сохраняет личные данные. Удалять их отдельно следует после выхода из MusicBridge и сохранения нужной резервной копии.
