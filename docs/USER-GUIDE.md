# MusicBridge rc44 и Music Wallpaper — руководство к кандидату

Состояние на 25 октября 2026: MusicBridge 1.0.0-rc44 [опубликован как предварительный выпуск](https://github.com/CloudW4lker250/MusicBridge/releases/tag/v1.0.0-rc44) и установлен поверх rc43 на рабочем ПК. Это релиз-кандидат; локальные проверки не означают прохождение всех условий стабильного выпуска. Для соединения с помощником нужен согласованный пакет Music Wallpaper rc44. Результаты фиксируются отдельно в `RELEASE-READINESS.md`; матрица испытаний — в `QA-PLAN.md`.

## Установка и первый запуск

MusicBridge рассчитан на Windows 10 2004 / сборку 19041 и новее, Windows 11, x64. Пакет содержит .NET; отдельно устанавливать среду выполнения не нужно. Работа на чистой Windows без .NET ещё должна пройти независимую проверку. Для музыки нужен плеер, публикующий медиасессию Windows; основной ранее проверявшийся источник — Яндекс Музыка. Приложение не заменяет музыкальный сервис.

1. На [странице rc44](https://github.com/CloudW4lker250/MusicBridge/releases/tag/v1.0.0-rc44) скачайте `MusicBridgeSetup.exe` и `MusicBridgeSetup.exe.sha256`. Сверьте сумму командой `Get-FileHash .\MusicBridgeSetup.exe -Algorithm SHA256`.
2. Запустите установщик обычным пользователем и нажмите «Установить». Он устанавливает приложение в `%LOCALAPPDATA%\Programs\MusicBridge`, создаёт ярлыки рабочего стола и меню «Пуск», запись в установленных приложениях. Права администратора не требуются.
3. В настройке подключения выберите язык и источник. Запустите музыку в своём плеере. Проверка пуска/паузы отправляет реальную команду только по нажатию и может изменить воспроизведение.
4. Через значок в трее откройте «Центр управления». В разделе «Музыка» доступны автоматический выбор, закрепление конкретной сессии и восстановление соединения. Браузер может объединять несколько вкладок в один источник.

Значок может находиться среди скрытых значков трея. По умолчанию × главного окна скрывает его в трей; «Выход» завершает программу. Автозапуск включается отдельно в настройках. Повторный запуск должен открыть существующий экземпляр.

## Что даёт приложение

Главное окно, плавающий мини-плеер и плашка панели задач показывают текущую песню. Пуск/пауза, предыдущая/следующая песня, перемотка и громкость доступны, если их предоставляет источник Windows. Громкость относится к определённой аудиосессии источника; для некоторых браузеров или плееров она может быть недоступна. Нажатие на синхронизированную строку текста перематывает к ней только при поддержке перемотки.

В «Центре управления → Мини-плеер» можно выбрать угол экрана, масштаб 80–125%, автоскрытие и задержку. Escape, повторное нажатие и щелчок снаружи закрывают всплывающую карточку. Плавающий мини-плеер имеет отдельное закрепление поверх окон.

«Библиотека» хранит локальные недавние прослушивания, избранное и таймер сна. Избранное не меняет аккаунт музыкального сервиса; сохранённая строка не запускает песню. Таймер отправляет паузу и работает, пока MusicBridge запущен. «Инструменты» относятся к песне, с которой открыты: свои TXT/LRC/Enhanced LRC, поправка синхронизации, закладки, повтор A–B, заметки, построчный перевод, открытка и музыкальный дневник. Перевод вводится или импортируется пользователем, автоматического перевода нет. При смене песни старое редактирование блокируется; откройте инструменты заново.

Караоке по словам требует настоящих временных меток слов. Для обычного текста точная синхронизация и движение слов не выдумываются. Текст, обложка, версия песни и тайминги могут отсутствовать или оказаться неточными во внешнем каталоге.

## Самостоятельные обои и помощник

Music Wallpaper — отдельный web-проект для Wallpaper Engine. Само приложение работает без Wallpaper Engine. Для обоев нужен отдельно установленный Wallpaper Engine. На [странице rc44](https://github.com/CloudW4lker250/MusicBridge/releases/tag/v1.0.0-rc44) скачайте `MusicWallpaper-rc44.zip` и его `.sha256`; архив содержит `project.json`, `index.html`, JS, CSS и ресурсы. Распакуйте полный архив в папку проекта, импортируйте как web-проект средствами Wallpaper Engine и примените к нужному монитору. После замены файлов повторно примените проект; в центре управления можно нажать «Обновить настройки с обоев». Обновление EXE не обновляет файлы обоев.

В rc44 соединение обоев с приложением защищено локальным ключом текущего пользователя Windows. У уже подключённого проекта в стандартной папке Music Wallpaper настройка выполняется автоматически. Если импортировали обновлённые обои в другую папку, один раз выберите её через «Центр управления → Музыка → Подключить папку Music Wallpaper…», затем заново примените проект. Вводить или пересылать токен не нужно. Без сопряжения самостоятельные функции обоев сохраняются; функции помощника ждут подключения.

| Возможность текущих Music Wallpaper | Без MusicBridge | С MusicBridge |
|---|---|---|
| Оформление, свой фон, расположение/масштаб, профили, часы, таймер фокуса | Да | Да; общий профиль синхронизируется с приложением |
| Аудиореакция | Через звуковой сигнал Wallpaper Engine | Через тот же сигнал |
| Название, исполнитель, обложка, состояние и позиция песни | Только если их передал Wallpaper Engine | Дополняются данными выбранной Windows-медиасессии |
| Текст песни | Прямой поиск LRCLIB при доступных данных песни и интернете | Расширенный поиск, свои тексты, поправки, заметки и переводы |
| Пуск/пауза, следующая/предыдущая, перемотка, громкость | Недоступны из этих обоев | По возможностям источника; недоступные команды скрыты или отключены |
| Погода, город, определение по IP | Прямые запросы к внешним сервисам | Те же запросы; дополнительно обычное окно ввода города |

Быстрые команды открываются значком с ползунками. Редактор позволяет двигать и масштабировать блоки, закреплять их, сбрасывать расположение и сохранять профили. Путешествие — лес, город или космос — двигается по доступной позиции песни; без неё камера не выдумывает прогресс. Земные погодные, сезонные и солнечные эффекты включаются только в лесном и городском путешествии. В космосе настройки сохраняются, эффекты отключены.

Для города используйте клавиатуру мышью на обоях либо свойство города в Wallpaper Engine, затем выберите результат. При работающем помощнике есть кнопка обычного окна ввода. «Определить город по IP» приблизительно определяет место только по нажатию; VPN может изменить результат. Погода обновляется примерно раз в 20 минут, после ошибки повторяется через пять минут; недавний кеш сохраняется. «Убрать город» очищает выбор. Часы и локальные вычисления даты продолжают работать без сети.

Своя видеообложка — локальный беззвучный WebM для всех песен, а не автоматическое видео к каждой песне. Файл нужно передавать отдельно: профиль не включает пользовательский ролик или фон. При ошибке файла или уменьшении движения используется обычная обложка.

## Обновление и удаление

В трее откройте «Обновления». По умолчанию автоматическая проверка начинается примерно через 25 секунд после запуска, затем раз в 12 часов; после ошибки — через 30 минут. Проверку можно отключить в настройках. Загрузка и установка требуют нажатия «Скачать и установить»; загрузку можно отменить и повторить. Более старая версия не заменяет новую.

Канал GitHub подписан RSA-PSS/SHA-256, установщик проверяется по размеру, SHA-256, продукту и версии. Это отдельная подпись канала, она не является Authenticode-подписью EXE. У rc44 Authenticode-подписи нет; оформление сертификата пользователь решил обсудить отдельно. Для ручного обновления запустите согласованный новый `MusicBridgeSetup.exe`. Перед заменой создаются копии `settings.json`, `library.json`, `track-tools.json`, `wallpaper-preferences.json` в `%LOCALAPPDATA%\MusicBridge\update-backups`. Новый запуск подтверждается версией, реальным PID и одноразовым кодом установки. Если подтверждения нет, установщик после остановки только своей новой копии пытается восстановить предыдущий EXE и четыре JSON из копии, сохраняя обнаруженные более поздние изменения пользователя. Ошибка восстановления указывает путь резервной копии. Эти меры не заменяют личную резервную копию.

Если Windows не разрешает завершить старый экземпляр, закройте его пунктом «Выход» в трее и повторите установку обычным пользователем. Разные уровни прав у MusicBridge, установщика и плеера могут мешать соединению. Не запускайте компоненты от администратора без необходимости.

Удаление: Windows → установленные приложения → MusicBridge → удалить. Оно убирает EXE, ярлыки, регистрацию удаления и автозапуск текущего пользователя. Настройки, история, избранное, кеш, журналы и резервные копии в `%LOCALAPPDATA%\MusicBridge` остаются; их можно сохранить или удалить отдельно после выхода из MusicBridge. Обои удаляются отдельно средствами Wallpaper Engine.

## Данные и внешние запросы

Локальные данные находятся в `%LOCALAPPDATA%\MusicBridge`. `library.json` содержит историю/избранное и поправки, `track-tools.json` — свои тексты и инструменты, `wallpaper-preferences.json` — общий профиль. Настройки обоев также сохраняются локально в хранилище web-проекта Wallpaper Engine. Смена папки проекта может привести к отдельному хранилищу; перед переносом экспортируйте нужные профили.

| Действие | Получатель и передаваемые сведения |
|---|---|
| Поиск текста/таймингов | LRCLIB; Better Lyrics; резервный поиск iTunes/Shazam. Название, исполнитель, иногда альбом и длительность |
| Улучшенная обложка | Deezer, iTunes, MusicBrainz, Cover Art Archive и адреса изображений из результатов. Сведения о песне/альбоме/исполнителе |
| Загрузка текста по своей ссылке | Genius или Shazam, только после ввода допустимой ссылки |
| Поиск города | Open-Meteo Geocoding: введённый город; сведения о городах основаны на GeoNames |
| Погода | Open-Meteo: координаты выбранного города, округлённые до четырёх знаков |
| Определение по IP | ipwho.is: запрос с публичного IP; только по кнопке |
| Обновления | GitHub/raw.githubusercontent.com; при загрузке — GitHub и его адреса доставки |

Все внешние сервисы видят обычные сетевые сведения, включая публичный IP. Отсутствие обязательного аккаунта MusicBridge не означает отсутствие внешних запросов. Сеть нужна для неизвестных обложек/текста, города, погоды и обновлений; уже сохранённые данные могут работать без сети. Кеш обложек/текста ограничен 400 файлами, 256 МБ и возрастом до 60 дней. Его очистка через центр управления сохраняет пользовательскую историю, избранное и инструменты.

Локальный API слушает `127.0.0.1:17832`, используется приложением и сопряжёнными обоями. В rc44 каждый обычный запрос требует локального ключа и заголовка клиента; обычный запрос браузера без ключа отклоняется. Ключ приложения хранится с защитой Windows DPAPI текущего пользователя. Сопряжение создаёт в локальной папке проекта частный `bridge-access.js`. Не включайте этот файл в публичный ZIP, публикацию обоев, снимки экрана, исходники или незашифрованную резервную копию. Публичный `bridge-access-client.js` — отдельный общий файл и должен входить в пакет. Не открывайте локальный порт наружу; доступ программ к файлам того же пользователя не исключается этой защитой.

В диагностике есть сохранение TXT-отчёта. По исходникам он исключает названия песен, текст, историю, имя пользователя, личные пути и исходные сообщения журнала. Автоматической отправки нет. Полные журналы, JSON, дампы, снимки рабочего стола и экспортированные открытки/дневники могут содержать личные данные; просмотрите их перед добровольной передачей.

## Если что-то не работает

Если трека нет, убедитесь, что плеер передаёт его в системную медиасессию Windows, затем используйте «Музыка → Восстановить подключение». После сна и разблокировки приложение запрашивает восстановление, но Windows и плеер могут задерживать данные. Неподдерживаемую команду MusicBridge не может добавить в сам источник.

Состояние обоев «Активно/Приостановлено/Не обнаружено» оценивается по сигналу проекта и процессу Wallpaper Engine; это не точный индикатор каждой его внутренней паузы.

Ранее зафиксирована редкая авария основного `wallpaper32.exe 2.8.42` (0xc0000005, смещение 0x64b98). Переключение правил полного/развёрнутого экрана с «Остановить» на «Пауза» прошло короткую проверку, но окончательное исправление не доказано. При повторе сохраните время и версию, при желании диагностический отчёт; не отправляйте дампы автоматически. Обновление MusicBridge не объявляется исправлением закрытого кода Wallpaper Engine.
