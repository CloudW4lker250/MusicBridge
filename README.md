# MusicBridge

MusicBridge — приложение для Windows, которое показывает текущий трек, управляет музыкой через системную медиасессию и передаёт данные в Music Wallpaper для Wallpaper Engine.

## Скачать и установить

[**Скачать MusicBridgeSetup.exe — 1.0.0-rc43**](https://github.com/CloudW4lker250/MusicBridge/releases/download/v1.0.0-rc43/MusicBridgeSetup.exe) · [Описание выпуска](https://github.com/CloudW4lker250/MusicBridge/releases/tag/v1.0.0-rc43)

Для работы нужна Windows 10/11 x64; .NET включён в сборку. Приложение устанавливается для текущего пользователя.

Музыкальный сервис должен передавать данные в системную медиасессию Windows. Возможности управления зависят от плеера.

## Обновления внутри приложения

Начиная с версии 1.0.0-rc43: значок MusicBridge в трее → **Обновления**. Доступны фоновая проверка, уведомление, описание новой версии, загрузка с прогрессом и отменой, установка с перезапуском. Канал выпусков подключён автоматически.

Перед запуском приложение проверяет подпись списка обновлений, размер и SHA-256 файла, название продукта и версию установщика. Загрузка и установка запускаются пользователем. Более старые версии не предлагаются.

Настройки, история, избранное и свои тексты хранятся отдельно от программы. Перед заменой создаётся резервная копия основных пользовательских файлов. Обои Wallpaper Engine обновляются отдельно.

Этот репозиторий используется для распространения выпусков и подписанного [update.json](https://raw.githubusercontent.com/CloudW4lker250/MusicBridge/main/update.json). Ключ подписи в репозитории не хранится.
