# MusicBridge

**MusicBridge 1.0.0** — приложение для Windows, которое показывает текущий трек в мини-плеере и соединяет музыкальный плеер с Music Wallpaper для Wallpaper Engine.

[Скачать MusicBridge 1.0.0](https://github.com/CloudW4lker250/MusicBridge/releases/tag/v1.0.0) · [Руководство](docs/USER-GUIDE.md) · [Ограничения](docs/LIMITATIONS.md)

## Возможности

- Мини-плеер в горизонтальном и компактном вертикальном виде: обложка, бегущее название, управление треками, перемотка и громкость.
- Частотный визуализатор, плавные переходы и автоматический игровой режим.
- Тексты песен, доступные тайминги, собственные TXT/LRC, заметки и поправка синхронизации.
- Локальные история и избранное, таймер сна и инструменты песни.
- Music Wallpaper: оформление, часы, фокус, собственный фон, путешествия, сезоны и погода.
- Обновления внутри приложения с проверкой цифровой подписи канала и сохранением пользовательских данных.

## Установка

1. Нужна Windows 10 версии 2004 (19041) или новее либо Windows 11, **x64**. .NET включён в установщик.
2. В выпуске скачайте **MusicBridgeSetup.exe**, запустите и нажмите «Установить». Права администратора обычно не нужны.
3. Включите музыку в плеере, который передаёт данные в медиасессию Windows. В центре управления выберите источник, если автоматический выбор не подошёл.
4. Для обоев отдельно установите Wallpaper Engine, скачайте **MusicWallpaper-1.0.0.zip**, распакуйте и импортируйте web-проект. При необходимости выберите его папку в «Центр управления → Музыка → Подключить папку Music Wallpaper…» и повторно примените обои.

Приложение работает и без Wallpaper Engine. Обои могут показывать оформление, часы и ряд других элементов без MusicBridge; управление музыкой и расширенные данные требуют работающего приложения. MusicBridge не заменяет музыкальный сервис.

Установщик пока **без подписи издателя Windows**: возможно предупреждение о неизвестном издателе. Подпись канала обновлений проверяет обновления приложения и не отменяет предупреждение Windows. SHA-256 файлов опубликованы рядом с установщиком.

## Обновление и помощь

В трее откройте «Обновления» или запустите новый установщик поверх прежней версии. Настройки, история и свои тексты сохраняются. Файлы обоев обновляются отдельно.

Данные хранятся локально в `%LOCALAPPDATA%\MusicBridge`. Для поиска текста, обложек, погоды и обновлений используются внешние сервисы: подробности в [руководстве](docs/USER-GUIDE.md#данные-и-внешние-запросы). Доступность обложек, текстов и команд зависит от источника.

Если возникла ошибка, [создайте issue](https://github.com/CloudW4lker250/MusicBridge/issues) с версией приложения, версией Windows и шагами повторения. Диагностический TXT можно сохранить в центре управления; перед публикацией просмотрите вложения. Не прикладывайте личные JSON, ключи подключения и дампы без проверки содержимого.

Этот репозиторий предназначен для выпусков и документации. Исходный код приложения не опубликован. Уведомления о сторонних компонентах доступны внутри приложения.
