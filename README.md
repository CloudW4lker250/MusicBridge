# MusicBridge

MusicBridge показывает текущий трек, управляет музыкой через системную медиасессию Windows и передаёт данные в Music Wallpaper для Wallpaper Engine.

## Скачать

[**MusicBridgeSetup.exe — 1.0.0-rc44**](https://github.com/CloudW4lker250/MusicBridge/releases/download/v1.0.0-rc44/MusicBridgeSetup.exe) · [Изменения и все файлы выпуска](https://github.com/CloudW4lker250/MusicBridge/releases/tag/v1.0.0-rc44)

[**Music Wallpaper rc44**](https://github.com/CloudW4lker250/MusicBridge/releases/download/v1.0.0-rc44/MusicWallpaper-rc44.zip) · [SHA-256 установщика](https://github.com/CloudW4lker250/MusicBridge/releases/download/v1.0.0-rc44/MusicBridgeSetup.exe.sha256)

Предварительный выпуск для Windows 10 2004+ / Windows 11 x64. .NET включён в пакет. Установка выполняется для текущего пользователя без прав администратора. Для музыки нужен плеер, который передаёт системную медиасессию Windows; возможности управления зависят от источника.

## Установка и подключение обоев

1. Скачайте и запустите установщик.
2. Запустите музыку в своём плеере. Выберите источник в центре управления MusicBridge.
3. Для Wallpaper Engine распакуйте полный пакет Music Wallpaper rc44 в папку web-проекта и примените проект.
4. Стандартная папка `myprojects/music_wallpaper` подключается автоматически. Если обои находятся в другой папке: **Центр управления → Музыка → Подключить папку Music Wallpaper…**

В rc44 используется защищённое подключение с локальным ключом пользователя. Нужны согласованные версии приложения и обоев. Личный файл `bridge-access.js` создаётся на компьютере пользователя; не передавайте его другим людям. EXE обновляет только приложение; файлы обоев обновляются отдельно.

## Обновления

Значок MusicBridge в трее → **Обновления**. Доступны проверка, уведомление, описание выпуска, загрузка с прогрессом и отменой, установка с перезапуском. Перед запуском проверяются подпись списка выпусков, размер, SHA-256 и версия установщика. Загрузка и установка запускаются пользователем.

Данные хранятся отдельно от EXE. Перед заменой установщик сохраняет копию основных файлов после остановки приложения. При неудачном запуске он восстанавливает предыдущую версию и данные, учитывая изменения после попытки обновления.

Подпись обновлений отличается от сертификата издателя Windows: сертификат для EXE пока не оформлен.

## Статус проверки

Локальные проверки rc44 и установка с сохранением данных пройдены. Проверка на чистых Windows 10/11, длительный прогон, сон/пробуждение, разные DPI и независимый пользовательский тест ещё требуются перед стабильным выпуском. Этот кандидат не объявлен стабильным.

Репозиторий распространяет выпуски и подписанный [список обновлений](https://raw.githubusercontent.com/CloudW4lker250/MusicBridge/main/update.json). Закрытые ключи и пользовательские данные здесь не хранятся.
